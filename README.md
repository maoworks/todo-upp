共有できるToDoカレンダーアプリを目標にした、操作確認用のローカル試作です。

2026年10月29日。企画責任者が操作を確認するための試作です。本番方式・一般公開・ストア申請は未決定です。

## 起動

Node.js 22以上で、このフォルダから次を実行します。追加パッケージのインストールは不要です。

```sh
npm start
```

ブラウザで http://127.0.0.1:3000 を開きます。停止はターミナルで Ctrl+C。
パソコン自身のみから接続する設定です。スマホへの配布・ストア用アプリはまだ作成していません。

## 保存について

この試作はブラウザ内の localStorage（端末内の小さな保存場所）を使います。MySQL等には接続しません。端末・ブラウザ・URLが変わるとデータは共有されません。閲覧履歴やサイトデータの削除、プライベートブラウズの終了等で失われることがあります。ホームからJSONのバックアップを書き出せますが、復元は未実装です。試用版として実利用する前に保存方式を判断してください。

外部サービス、解析ツール、外部フォントは使いません。氏名・メールアドレスの入力欄はありませんが、ToDo名・メモには個人情報を書けるため、端末を他人に貸す場合には注意が必要です。認証・暗号化・複数端末同期は未実装です。

## 技術テスト


テスト用ブラウザには一時的なデータだけを作成します。実利用データは削除しません。

## 保存先

現在の成果物は作業環境の `/workspace/ToDoリスト` に保存しました。指定された既存の「ToDoリスト／ドゥドゥリスト」フォルダは未特定です。Google Driveの同名フォルダへ保存したという意味ではありません。保存場所の確認後、既存資料と統合します。
