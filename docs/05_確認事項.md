# 未決事項と確認のお願い v0.1

細かな仕様が決まるまで全作業を止めず、下表の暫定案で試作しました。本番方式、操作を大きく変える判断、外部サービス・費用・個人情報の扱いは未決定です。

## 先に確認したいこと

|優先|質問・不明点|選択肢と推奨案|影響|
|---|---|---|---|
|1|指定フォルダ・最新要件定義書はどこか|フォルダURLか保存場所を確認|正式要件との照合。現在はローカルの新規フォルダに保存|
|1|いとこ・おばの端末OS、複数端末で使うか|iPhone／Android、端末内のみ／同期ありを確認|技術方式、配布、費用、個人情報の扱い|
|1|本番技術をどれにするか|スマホ中心・同期なしならTypeScript＋React Native＋SQLite、Java学習・サーバー同期重視ならJava＋Spring Boot＋MySQLを推奨|方式決定前に本番の構成を固定しない|
|1|4色の意味は重要度だけか、やりたい／義務との対応があるか|当面は優先度だけ。分類の追加は利用者の必要を確認して判断|解決する課題と集計の意味が変わる|
|1|試用開始日・期間・公開目標|12月までの試用版、1〜3月の約3か月試用を仮置き|1か月以上の実利用を確保。4月公開は確約しない|

|繰り返し|月末、うるう日、未完了の繰越、系列編集|未実装。必要頻度を聞き、まず毎週等に限定する案|
