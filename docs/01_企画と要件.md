# 企画と要件の整理 v0.1（レビュー用）

作成：AI、2026-10-29。企画責任者の承認前。

## 目的と根拠

初期利用者はいとことおば。やりたいことと義務の整理、優先順位付けが難しく、義務に予想以上の時間がかかり、やりたいことの時間が残らない。これは今回の依頼で企画責任者から共有されたヒアリングの要約であり、AIが直接聞いた発言ではない。

「予定と実績を振り返ると時間の使い方を理解できる」「シンプルなら継続しやすい」は検証する仮説。効果が出たという実績はまだない。利用者の実際の発言は今後、同意を得て匿名で記録する。

## シンプルさへの対応

フォルダは2列、下部はホーム・一覧・結果・計測の4つに絞る。名前だけでToDoを作れ、予定・期限・メモは任意。優先度は緑を初期値とする。色だけでなく文字と旗を併記する。グラフの装飾よりも完了数と時間の意味を優先した。これらが使いやすいかは企画責任者と利用者が確認する。

「やりたい／やる必要」の独立した分類は設計資料で確定していないため追加していない。4色の意味を確認してから判断する。
